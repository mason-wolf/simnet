# simnet

A lightweight network simulation tool for threat hunting.


It supports investigating artifacts associated with common persistence and execution behaviors, including:

- filesystem activity
- registry entries
- security and system events
- services and startup mechanisms
- scheduled tasks
- process and network-related host telemetry

Useful for:

- malware persistence simulations
- Windows forensic walkthroughs
- threat hunting exercises
- command-line behavior training
- SOC-style triage practice
